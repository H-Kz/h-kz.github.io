# Aura Drive | Next-Gen Web Navigation

Aura Drive is a premium, web-based car navigation system built with modern web technologies.

## Key Features
- **Vector Map Engine**: Powered by MapLibre GL JS for silky smooth 60fps performance.
- **Glassmorphic UI**: High-contrast, dark-mode interface designed for optimal visibility in vehicles.
- **Real-time Tracking**: Precise location tracking and speed calculation.
- **Modern Tech Stack**: HTML5, Vanilla CSS3, JavaScript (ES6+), Lucide Icons.

## Setup & Run
Simply open `index.html` in a modern browser. For the best experience, use a local server:

```bash
npx serve ./
```
